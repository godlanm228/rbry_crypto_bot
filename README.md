# RBRY CryptoBot

Telegram crypto assistant for portfolio tracking, market monitoring, and analysis.

## Features
- Portfolio tracking
- Market snapshots (prices, 1h/24h/7d changes)
- Alerts (stop-loss / take-profit / market events)
- News digest
- Tiered access control

## Commands
- /start
- /help
- /portfolio
- /add_entry COIN AMOUNT PRICE
- /sell COIN AMOUNT PRICE
- /stats
- /movers
- /analyze
- /news

## Quick start
```bash
pip install -r requirements.txt
python main.py
```
